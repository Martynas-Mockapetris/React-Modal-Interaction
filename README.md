# React Flight Booking Modal

An interactive flight booking modal built with React and Tailwind CSS. The project focuses on creative UI design, smooth transitions, and interactive animations to create an engaging flight booking experience.

## ✨ Features

- **Animated Booking Button** — Interactive button with 3D rotation, animated text, and plane transitions.
- **Interactive Modal** — Opens a flight booking modal with smooth transitions and animations.
- **Click Outside to Close** — Close the modal by clicking on the background overlay.
- **Image Gallery** — Displays a collection of travel images with randomized rotation effects.
- **Flight Offers** — Showcases available flight offers in a structured grid layout.
- **Interactive Elements** — Animated hover effects, transitions, and interactive button states.
- **Component-Based Structure** — Uses a separate background component and reusable data imports.

## 🛠️ Technologies Used

- **React** — Component-based UI development.
- **JavaScript (ES6+)** — Application logic, event handling, and dynamic content rendering.
- **Vite** — Development server and production build tooling.
- **Tailwind CSS v4** — Utility-first styling, responsive layouts, and interactive animations.
- **React Hooks** — `useState` for modal visibility, `useEffect` for event listener management, and `useRef` for referencing DOM elements.
- **CSS3** — Additional styling and visual effects.
- **HTML5** — Application structure and markup.
- **Git & GitHub** — Version control and source code hosting.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Martynas-Mockapetris/React-Modal-Interaction.git
   ```

2. Navigate to the project directory:

   ```bash
   cd React-Modal-Interaction
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided in your terminal, typically `http://localhost:5173`.
